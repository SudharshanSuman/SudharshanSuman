# Sudharshan S

**Robotics and Embodied AI | Isaac Lab, Warp, ROS 2**

I build simulation and control software for robots that have to work in messy, real-world settings.

## Featured work

- **[GPU-Accelerated Plant Biomechanics](https://github.com/SudharshanSuman/gpu-accelerated-plant-biomechanics)**: a NVIDIA Warp solver that models crop stems and canopies as deformable bodies, with an Isaac Sim bridge for agricultural robots.
- **[Understanding the Prompt to Robot](https://github.com/SudharshanSuman/Understanding-the-Prompt-to-Robot)**: natural-language control of a simulated Franka Panda arm, with deterministic safety validation and MoveIt 2 planning in Gazebo.
- **[Student Project Tracker](https://github.com/SudharshanSuman/student-project-tracker)**: a full-stack management platform for a university Innovation Incubation Cell.
